# 디자인 레퍼런스 인덱스 (guidelines/designs)

이 디렉토리의 PNG는 “참고 UI 레퍼런스”입니다. 파일명만 보고도 어떤 화면/상태인지 추적 가능하도록 아래에 매핑합니다.

## 전체 사용자 플로우(레퍼런스 기준)

1. 예약 페이지 목록(템플릿 카드 리스트)
2. 예약된 일정 목록(다가오는/대기/지난)
3. 날짜 선택 + 시간 선택(캘린더 + 타임 리스트)
4. 예약자 정보 입력(이름/이메일/메모)
5. 예약 완료(요약 + 캘린더 저장)

---

## 파일 매핑

### `booking-list.png`
- **의미**: 예약 페이지(템플릿) 목록
- **핵심 UI**:
  - 상단 탭/내비게이션
  - "예약 페이지" 탭 활성
  - 카드 그리드(각 템플릿: 제목, 소요시간, 타입/그룹, 위치 등)
  - 카드 하단 액션(예약페이지 열기/복사/공유)
  - 우상단 "+ 만들기" CTA

### `dashboard.png`
- **의미**: 예약된 일정 목록
- **핵심 UI**:
  - “예약된 일정” 탭 활성
  - 서브 탭(다가오는/대기/지난)
  - 날짜 섹션 헤더 + 일정 행(row)
  - 우측 유틸 액션(다운로드/필터)

### `response-1.png`
- **의미**: 날짜 선택 + 시간 선택(시간을 직접 입력하여 하나의 시간대를 선택하는 상태)
- **핵심 UI**:
  - 좌측: 예약 정보 요약(제목/소요시간/미팅방법/선택 날짜/시간)
  - 중앙: 캘린더(원형 날짜 버튼)
  - 우측: 시간 선택(단일 입력 형태)

### `response-2.png`
- **의미**: 날짜 선택 + 시간 선택(시간 리스트 선택 상태)
- **핵심 UI**:
  - 우측 시간 선택이 리스트 형태(스크롤)
  - 선택 날짜 강조

### `response-3.png`
- **의미**: 예약자 정보 입력
- **핵심 UI**:
  - 좌측 요약 + 뒤로가기
  - 우측 폼(이름*, 이메일*, 메모)
  - 하단 제출 CTA

### `response-4.png`
- **의미**: 예약 완료
- **핵심 UI**:
  - 완료 메시지
  - 예약자 정보/이메일/미팅방법
  - 상세 일정(날짜/시간)
  - 캘린더 저장 액션

---

## 구현 적용 범위(예정)

- **프론트엔드**: Create/Response/Dashboard 흐름을 위 레퍼런스와 일관된 구조로 정렬
- **API**: 시간 슬롯 생성 규칙(주말 포함 여부, interval/duration 반영)을 단일 규칙으로 통일

> 레퍼런스는 “화면 구조/정보 계층/CTA 위치/상태 표현”을 우선 적용하고, 세부 컬러/타이포그래피는 기존 MUI 토큰과 충돌 없이 점진 적용합니다.
