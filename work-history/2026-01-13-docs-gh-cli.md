## 수행 작업
- `README.md`의 사전 요구사항에 GitHub CLI(`gh`) 설치 절차(플랫폼별 명령, 버전 확인, 로그인)를 명시하여 PR/gh 관련 작업을 안내함.
- `TOOLING_SETUP.md`에도 `gh` 설치 안내 섹션을 추가해 세팅 문서 전반에 일관된 지침을 보강함.

## 의사결정/이슈
- `gh` 없이 GitHub 상호작용(PR 등)을 진행할 수 없다는 피드백을 반영해서 setup 문서와 툴 가이드 모두에 도구 설치 정보를 중복 없이 제공하도록 함.

## 해결 방법
- 각 OS별 설치 명령과 `gh auth login` 절차를 간단하게 설명하고, 설치 후 확인 단계도 함께 기록해서 누락 없이 따라할 수 있게 구성.
